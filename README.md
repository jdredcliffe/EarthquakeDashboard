# Earthquake Dashboard

A Qt/QML dashboard that fetches recent earthquakes from the USGS Earthquake API (REST, JSON), processes the data in C++ and presents it in QML.

Individual assignment, Project 2 – REST API, Fagskolen Viken.

## Requirements

- Qt 6.5 or newer (Qt Quick, Qt Quick Controls, Qt Network)
- CMake 3.16 or newer
- A C++17 compiler

## Build and run

1. Open `CMakeLists.txt` in Qt Creator.
2. Select a Qt 6 kit.
3. Press Run.

## API

Data: U.S. Geological Survey (USGS) Earthquake Hazards Program, https://earthquake.usgs.gov/fdsnws/event/1/

No API key is needed.
